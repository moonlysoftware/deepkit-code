# Original document fixtures

The paper, invoice, two-page manual and image-only scanned PDF are original
synthetic content, generated by `python3 scripts/corpus/make-pdf-fixtures.py`.
The paper includes two independently positioned columns. The manual has a UTF-16
metadata title; the invoice exercises file-name fallback. No third-party PDF
content is copied. Each file is below 1 MB.

The encrypted invoice was generated with qpdf:

```
qpdf --encrypt fixture-user fixture-owner 256 -- fixtures/docs/invoice.pdf fixtures/docs/encrypted.pdf
```

These public fixture passwords protect only synthetic test data. qpdf encryption
uses random values, so regeneration need not reproduce the ciphertext bytes.
Tests consume the committed small encrypted file and do not require qpdf.

Large page-cap fixtures are generated in a temporary directory during tests:

```
python3 scripts/corpus/make-pdf-fixtures.py --pages 600 --output /tmp/dkc-pdf-fixtures
```

Never commit the generated large corpus. T3.6 will add embedded JPEG scan and
VLM-specific cases.
